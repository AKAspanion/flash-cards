# Read Aloud (Device and Natural Voice) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: the project's workflow policy names the executor (`run.executor`): ga:implement-with-subagents by default, or ga:implement. Follow the policy and this plan's Checkpoints. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a speaker button to each card side: free users hear the device voice, Pro users hear a natural Cloud Text-to-Speech voice that is cached on the device.

**Architecture:** One new callable behind the existing AI gateway, `speakText`, returns an MP3 (base64) from Cloud Text-to-Speech for a card side in the app's language. The app plays it from a Blob URL and keeps the clip in Cache Storage keyed by text + language + voice, so replaying never calls the function. Free users (and any side over the length limit) use the browser's `speechSynthesis`, which sends nothing anywhere.

**Tech Stack:** App: Vue 3.5, Vuetify 4, Pinia 4, vue-i18n 11, Firebase JS SDK 13, Web Speech API, Cache Storage API, Vitest 5, Playwright 1.64. Functions: `nodejs22`, `firebase-functions` v2, `@google-cloud/text-to-speech` (Application Default Credentials), `zod`, Vitest. Emulators via `npx --yes firebase-tools@15.34.2`. CI: GitHub Actions, unchanged by this plan.

**Spec:** `docs/specs/2026-11-02-ai-features.md`

Which voice: Pro users (`canUse('speakNatural')`) get the natural voice for sides of 1–500 characters; free users, and any side over 500 characters, get the device voice. Natural path: build the key from the text, the app language and `NATURAL_VOICES[lang].name`; a cached clip plays at once with no network call; otherwise `useAiStore().run('speakNatural', () => callAi('speakText', { text, lang }))`, decode the base64 to an `audio/mpeg` Blob, store it, and play it from a Blob URL (revoked when playback ends or stops). Device path: cancel any utterance, then speak one with `lang` = `DEVICE_VOICE_LANG[lang]`. When neither voice is available, the button is not shown. The button is disabled when the side is empty (the example placeholder text is never read). Leaving the card (unmount) stops its playback.
